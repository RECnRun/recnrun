# Architecture decision records

Each record states one decision, the context that forced it, and what it changes. A record is never rewritten after it is accepted; a later record supersedes it and says so.

| ------------------------------------------- | ------------------------------------------- | ---------------------- |

New records take the next number and the name `NNNN-short-title.md`, with the sections Status, Context, Decision, and Consequences. [ARCHITECTURE.md](../ARCHITECTURE.md) describes the result; the records explain why.
